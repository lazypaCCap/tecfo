#开始  
下载仓库，确保LziciCUI.py;Lzicicore.py和LziciCLI.py在同一目录  
在带textual的python环境下,LziciCUI.py同目录执行./LziciCUI.py  
使用ctrl+e关闭，前往~/.config/Lzici/设置.json补上“模型名”字段，内容填你的模型名  
再次执行./LziciCUI.py
